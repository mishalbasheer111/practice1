CSC350 Practice Set 1 — Python Basics and OOP
================================================

Files:
  p1.py through p10.py — one Python solution per problem
  stock.txt            — input data for Problem 10

How to run:
1. Put all files in the same folder.
2. Open a terminal in that folder.
3. Run each problem separately, for example:
       python p1.py
       python p2.py
   ...
       python p10.py

Important:
- p10.py expects stock.txt to be in the same folder.
- Read and understand each solution, run it, and be prepared to explain
  how it works. The practice-set instructions say the work is individual
  and that copied solutions receive zero.
